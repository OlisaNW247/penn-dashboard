# onboarding checklist

The same five steps that appear on each ambassador's page
(`worker/templates/checklist.json`). For the founders, the steps *before*
that:

**founder side, 3 minutes per friend**
1. open the founder view, "add an ambassador": name, school, phone.
2. tap "text the welcome". it opens messages pre-filled with their private
   link. send it.
3. tap "mark sent".

**ambassador side, 15 minutes, no login**
- [ ] download smooth and connect canvas
- [ ] send one piece of feedback (what confused you counts)
- [ ] drop one message in one chat
- [ ] post once on fizz / sidechat / yik yak
- [ ] optional: put up a poster or two, log it

That's the whole onboarding. Status moves from `invited` to `active` the
first time their link is opened or they log something.
