Direction A = Smooth's own in-app feature runs on the student's AI account. Direction B = the student's AI app uses Smooth as a connector/tool.
Method: WebFetch/WebSearch only. Most official pages show relative dates ("Updated N days ago") or none; noted per item. Many search results were third-party and are marked "secondary". Nothing was answered from memory.

## 1. OpenAI "Sign in with ChatGPT" + plan usage (Direction A)
- Help page https://help.openai.com/en/articles/20001542 ("Updated: 12 days ago"): "We've launched with a limited set of partners." Commercial partners complete an interest form; open-source developers use the developer docs. Plans: Go, Plus, Pro, Business (anyone can sign in; only eligible plans get plan usage; each app may restrict plans further). "Some capabilities available in ChatGPT or through the OpenAI API may not be available" in other apps.
- Developer docs https://developers.openai.com/siwc and https://developers.openai.com/siwc/llms-full.txt: "currently available to selected commercial partners through a limited trial." Plan usage is "aimed at open-source and locally hosted apps"; paid or remotely hosted apps are pointed to the interest form; client IDs are by waitlist. Docs text names Plus and Pro (help page also lists Go/Business: conflict, re-check).
- Native iOS: NOT supported as documented. Registration uses an HTTP loopback redirect on 127.0.0.1 ("Do not substitute with localhost"; only the port may vary; https://developers.openai.com/siwc/token-sharing-open-source/sign-in). No custom URI scheme or universal link is described. A shipped iPhone app with a backend is "remotely hosted/commercial" -> partner track only.
- Required UI (llms-full.txt): welcome modal once; "Using ChatGPT plan" indicator near composer/model picker with Manage-usage link; plan usage separated from app's own charges; limit-reached state with Manage usage as primary action; list eligible plans on pricing.
- Preview limits: `store` false and `stream` true on every request; no system role item (use `instructions`); temperature, top-p, token caps, metadata, truncation, user etc. unsupported; no hosted MCP/connectors, file search, image gen, Files API; only function/custom tools. Usage errors can arrive mid-stream as `response.failed`; 429 `subscription_sharing_usage_limit_exceeded` must not be read as "plan empty". OpenAI does not notify apps when a user disconnects.
- Secondary (WorkOS https://workos.com/blog/sign-in-with-chatgpt-plan-usage-scope ; DEV/other write-ups): scope `chatgpt.tokens.use.direct`; weekly per-app cap; Plus shares one five-hour window across apps; 16 launch partners at DevDay 2026-09-29 (Amp, Devin, Warp, OpenClaw, Lovable named); credits spend off by default. Help page (via search summary) says some SaaS names (Airtable, Canva, GitLab, HubSpot, Supabase) "not available" for token sharing. No change since October found beyond the above.
- Surprise: the identity-only "Sign in with ChatGPT" (website guide https://developers.openai.com/siwc/website) is broader than plan usage, but gives no model access.
- Verdict: A is possible only by applying to the partner/interest form; not self-serve for a native iPhone app today.

## 2. ChatGPT as a client of Smooth (Direction B)
- Help https://help.openai.com/en/articles/12584461 (via first fetch, "Updated 28 days ago", unconfirmed): Business and Enterprise/Edu can connect custom MCP with write actions; Pro can build apps via the Apps SDK and connect custom MCP with read/fetch only; custom MCP "can't be added on mobile" (web only). Secondary sources say Plus can use developer mode read-only and Free cannot; community posts report the option moving between plans.
- Developer mode guide https://developers.openai.com/api/docs/guides/developer-mode.md: web setup; tools with `readOnlyHint` are read, others write and ask confirmation.
- Directory: https://developers.openai.com/apps-sdk/deploy/submission : needs org owner or Apps Management Write, individual/business verification, domain verification file `/.well-known/openai-apps-challenge`, privacy/terms/support URLs, test accounts, 5 positive + 3 negative test cases, video. No unlisted option documented.
- UI: https://developers.openai.com/apps-sdk says plugins can "Return optional UI resources from selected MCP tools" (rendered components). iOS rendering not confirmed. https://help.openai.com/en/articles/11487775-connectors-in-chatgpt notes apps/plugins exist on web, desktop and iOS, with Read/Low-risk/All action permissions, but does not cover custom ones.
- Scheduled tasks launched 2026-06-17 (9to5mac, https://9to5mac.com/2026/06/17/openai-launches-scheduled-tasks-in-chatgpt-details-here/), replacing Pulse; monitoring tasks can check connected apps; plan list conflicts (Plus/Pro/Business vs also Go). Agent mode + MCP: not verified.
- Verdict: B is feasible for a student on Pro (read-only, web) or via a published directory listing (needs verification, review). Unlisted consumer install on Free/Plus/mobile: not confirmed. Note the account identity problem: Smooth's phone-held data would have to be pushed to a server for a remote MCP to read it.

## 3. Google Gemini
- Direction A: no official route where an app spends a user's Gemini subscription. Only secondary: Puter says there is no OAuth flow billing a user's Google AI subscription (https://developer.puter.com/tutorials/gemini-oauth/), and Firebase AI Logic is a developer-side proxy billed to the developer (https://firebase.google.com/docs/ai-logic). Google forum asks for delegated usage, unanswered (https://discuss.ai.google.dev/t/question-should-ai-apis-support-oauth-style-user-authorized-usage-delegation/171723). An unofficial Gemini-CLI-token trick exists; do not use.
- BYOK free key: AI Studio terms (effective March 23, 2026) https://aistudio.google.com/docs/terms : Google may use content "to provide, improve, and develop" products on unpaid services; "human reviewers may read, annotate, and process your API input and output"; "Do not submit sensitive, confidential, or personal information to the Unpaid Services."; users must be 18+ and you may not offer an API client likely used by under-18s; EEA/UK/Switzerland clients must use paid services. Rate limits are per project, not per key (https://aistudio.google.com/docs/rate-limits). BYOK-in-an-app terms status unclear (forum: https://discuss.ai.google.dev/t/are-bring-your-own-api-key-apps-ok-under-google-geminis-tos/5127). Pasting a key into an iPhone app is feasible technically but sends coursework to a training-eligible free tier.
- Direction B: https://support.google.com/gemini/answer/13695044 says you can "connect personal or third-party apps by linking their Model Context Protocol (MCP) server" (Connected Apps), availability "varies by location, language, device"; a search summary says custom apps need Gemini Spark access (TechRepublic, secondary, https://www.techrepublic.com/article/news-gemini-spark-app-integrations/). Unconfirmed on iOS.
- Student offer (https://blog.google/products-and-platforms/products/education/back-to-school-2026/, 2026-08-19): US college students get a year of Google AI Pro free (includes Spark); elsewhere Google AI Plus. Redeemable through 2026-12-31 per a search summary; card required, auto-renews at $19.99 (secondary: macrumors.com/2026/08/19/students-free-year-google-ai-pro). Claim at gemini.google.com/students. The subscription does not give API quota.

## 5. User-pays brokers (Direction A)
- OpenRouter PKCE https://openrouter.ai/docs/guides/overview/auth/oauth : PKCE S256 required; code exchanged at `/api/v1/auth/keys` for a user-controlled key billed to the user's credits; https or localhost callbacks; headless copy-paste fallback; custom schemes mentioned only as a risk (other apps can claim the same scheme), so iOS needs a universal link/https callback or ASWebAuthenticationSession; optional `limit` credit cap. Fees https://openrouter.ai/docs/faq : 5.5% credit purchase fee, $0.80 minimum; no top-up minimum stated; free models 50 requests/day, 1,000/day with at least 10 credits bought; prompts not logged by default but some endpoints may train unless the user's privacy toggle blocks them. Best fit of all routes for a native app, but students must buy credits.
- Hugging Face (secondary snippets): OAuth `inference-api` scope lets apps call Inference Providers on the user's behalf, billed to the user (free $0.10/month, PRO $2). Native/PKCE support not verified (fetch timed out). https://huggingface.co/docs/hub/en/oauth
- Puter.js "User-Pays": https://docs.puter.com/user-pays-model/ ; browser JavaScript only, no iOS SDK found (would need a WebView).
- Vercel AI Gateway: team BYOK only; no end-user billing flow found (https://vercel.com/docs/ai-gateway/byok).

## 6. Student experience, data flow, App Store
- ChatGPT plan usage (A): student taps "Continue with ChatGPT", consents, sees "Using ChatGPT plan" and caps; prompts go from phone (or Smooth backend) to OpenAI under the student's account, with context and work-list text included. Needs partner approval first.
- OpenRouter (A): student signs in, tops up credits, key lives in iOS Keychain; prompts go straight to OpenRouter and routed providers.
- Gemini BYOK (A): student creates AI Studio key and pastes it; free tier data may be reviewed/trained on.
- B routes: the student adds Smooth in the AI app; the AI vendor's model reads whatever Smooth's server exposes, so Smooth would need a server-side copy of data (conflicts with Smooth's "stays on-device" stance unless the student opts in).
- App Store (Apple guidelines https://developer.apple.com/app-store/review/guidelines/, undated): 5.1.2(i) "You must clearly disclose where personal data will be shared with third parties, including with third-party AI, and obtain explicit permission before doing so." Applies to every route; sharing grades or work lists with the student's chosen provider needs an in-app disclosure and consent. 4.8: third-party sign-in used to set up the app's primary account needs an equivalent privacy-preserving option; sign-in used only to attach an AI provider (not the app account) should not trigger it, but a Smooth account created via ChatGPT would. 5.1.1(v): if accounts are created, in-app deletion is required (Smooth's disconnect already deletes). 3.1.1: a feature unlocked by a third-party subscription is arguably not IAP-covered because Smooth sells nothing; do not sell credits or paid tiers for these features outside IAP. This is my reading, not Apple's; flagged for App Review confirmation.

## Surprises
- ChatGPT plan usage is Responses-only, no system role and no hosted MCP, and requires 127.0.0.1 loopback redirects: a native iOS client is not a documented target.
- Gemini free API terms bar apps likely used by under-18s and require paid services for EEA users.
- ChatGPT custom MCP reportedly web-only, with Pro read-only.
