## The idea, in three sentences

Smooth should not just mirror the Canvas calendar. It should read
everything a class publishes (modules, pages, syllabus, announcements,
Ed) once, so a cancelled homework disappears, a moved quiz moves, and a
task that only lives in a module shows up. The model never writes the
list: it emits small facts with a quote, and code applies them to the
dashboard with provenance and undo, and never completes or deletes
anything.

The full design is `docs/DAY_PLANNER_RESEARCH_2026-11-03.md` (Part 2.3 is
the precedence spec; the Addendum is the part to re-read).

## Traps from this work (also in CLAUDE.md where they belong)

- A new SwiftData model goes in its own store file, never in the ledger's
  schema. The ledger's migration has never opened a real pre-existing store.
  The wrong fix is a `LedgerSchemaV2`.
- Canvas-derived completions, dismissals and dates are not student edits.
  The wrong fix is `setCompleted` or a write into `dueDateEdits`.
- A cancel only hides and tags; medium-confidence cancels are never applied.
  A cancelled item already overdue appears nowhere (todo hides it, all
  excludes overdue, prev is completed-only).
- A student's AI-assist switch does not stop course-level extraction of posts
  a classmate pooled (`docs/PRIVACY.md` says so).
- The cap reads in `claim_fact_extraction` are plain sums and can overshoot.
- Pooled assignment text used to carry "Status: submitted"; removed today.
  Documents already in the pool keep it until their next revision.
- From 2026-11-03, still true: the pool's index is today's state, Ed
  `updatedAt` is the last edit, `provider.require_parameters` 404s Haiku, and
  `devicectl` cannot copy root-level App Group files.
