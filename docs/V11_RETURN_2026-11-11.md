## How the agent connection works (five steps)

1. **Connect.** In Claude's settings the student adds Smooth as a connector
   (`https://smooth-agent.vercel.app/functions/v1/mcp`). Claude opens our
   sign-in page; the page shows a short code and a number.
2. **Approve on the phone.** The student taps "Open Smooth" (or types the
   code under Profile → agent → "have a code?") and picks the matching number
   in the approve sheet. A wrong number denies it. Approving turns the
   "connected agent" switch on.
3. **Claude reads.** With the switch on, the phone uploads the work list
   (classes, assignments, own tasks; never grades, name or cookies) every
   10 minutes while the app is open. Claude can list courses and work, read
   pooled course material and assignment PDFs, announcements, Ed posts and
   facts. Nothing can submit.
4. **Claude drafts.** `propose_submission` leaves a draft (text, link or
   file) for one assignment. The phone polls every 5 minutes, puts "drafted
   by claude" on the card and sends one notification.
5. **The student submits.** The card's "review and submit" opens the sheet:
   the draft, what Canvas accepts, then "submit to canvas" or "decline". The
   phone sends it to Canvas with the student's own session, once, and the
   card goes to prev as "submitted by you · drafted by claude". Off (the
   switch, disconnecting Canvas, deleting the account) deletes the server's
   list and disconnects every agent.
