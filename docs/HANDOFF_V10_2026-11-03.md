## The idea, in three sentences

Smooth should not just mirror the Canvas calendar. It should read
everything a class publishes (modules, pages, syllabus, announcements,
Ed) once, keep a map of the term, and then read each new post against
that map so a cancelled homework disappears, a moved quiz moves, and a
task that only lives in a module shows up. The model never writes the
list: it emits small facts with a quote, and code applies them to the
ledger with provenance and undo.

The full design is `docs/DAY_PLANNER_RESEARCH_2026-11-03.md` (Parts 2
and the Addendum are the ones to re-read).

## How to run the bench again

```bash
cd backend && OPENROUTER_API_KEY="$(tr -d '[:space:]' < ~/lhf-bench/openrouter.key)" \
  deno run --allow-net --allow-read --allow-write --allow-env bench/extract-facts/run.ts \
  --corpus bench/extract-facts/corpus/phone/marco --tag <tag> --model anthropic/claude-haiku-5.5 --reasoning low
```

The key is Marco's OpenRouter key in that file (chmod 600); never paste
it anywhere. `deno run --allow-read --allow-write bench/extract-facts/score.ts
--results results/<tag>.jsonl --corpus <corpus dir>` rescores after a
relabel without new model calls. `pull-from-phone.sh` refreshes the real
corpus from a paired iPhone running a DEBUG build.

## Traps from this work (also in CLAUDE.md where they belong)

- The pool's document index is today's Canvas state; extraction runs at
  post time, so the bench rewinds each file's index by hand.
- Ed `updatedAt` is the last edit, not the post date.
- `provider.require_parameters` on OpenRouter 404s Haiku; strict
  `json_schema` alone works. Anthropic's schema mode rejects `null` in
  an enum list; use `anyOf`.
- `devicectl` cannot list or copy root-level files in the App Group
  container (the ledger); the course pool under `Library/Application
  Support` copies fine.
