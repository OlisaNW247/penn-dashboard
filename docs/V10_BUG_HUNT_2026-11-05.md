# v10 bug hunt, 2026-11-05

Read-only review of everything on `v10` since `v8` (59 commits, `e99f295`),
for the parallel v10 thread. Nothing here is fixed. Baselines re-run on
Marco's Mac today: `swift test --no-parallel` 3631 / 348 green (112 s),
`deno task test` 693 green, `deno task check` clean; no Swift changed since
the last iOS build (`08b2e77`). Six reviewers read the code by area; each
item below marked **[seen]** was re-read in the code by the overseer, the
rest are **[reviewer]** findings traced by one reviewer only.

Paths are under `LowHangingFruitKit/Sources/` unless they start with
`backend/`, `chrome-extension/` or `.github/`.

## Severe: wrong state on a student's dashboard

1. **Opening an assignment in Canvas marks it done in Smooth.** [seen]
   `LowHangingFruitKit/Canvas/CanvasStructuredSourcesReconciler.swift:130`
   counts any module `completion_requirement.completed == true` as a
   completion without reading the type, which is parsed and never used
   (`CanvasStructuredSources.swift:146`). A `must_view` requirement on an
   assignment item (common gating) completes the card.
2. **A Canvas-derived completion can never be undone.** [seen]
   `structuredCompletedItemIDs` only ever grows
   (`LowHangingFruitUI/AppState+StructuredSources.swift:200`), nothing but
   disconnect clears it, and `markActive` (`AppState.swift:8921`) does not
   touch it, while `isCompleted` (`AppState.swift:9010`) honours it. Swipe
   back to active and the next rebuild re-completes it; un-ticking in Canvas
   does nothing either. Together with 1 this is the worst pair.
3. **Undo of a fact does not last.** [seen]
   `LowHangingFruitKit/Facts/FactApplication.swift:172-195` drops a
   `.rejected` fact before supersession, so any other live fact with the same
   (course, type, target) applies: a typo edit to the post (new hash, old
   facts pruned with the verdict), a second post saying the same thing, or a
   server re-extraction (item 13). The un-cancelled card is cancelled again.
4. **A newer reschedule never lifts an older cancel.** [seen]
   The supersession key includes the fact type
   (`FactApplication.swift:417-421`), so "Quiz 2 cancelled" (Nov 1) and
   "Quiz 2 back on, Nov 10" (Nov 3) both apply: moved and hidden.
5. **A cancelled item that goes overdue is in no view and undo is unreachable.** [seen]
   todo excludes cancelled, all uses `includeOverdue: false`, prev is
   completed-only (`LowHangingFruitUI/DashboardViewModel.swift:390-424`); the
   megaphone's "changed" row is a link with no undo
   (`AnnouncementFindsView.swift:274`). The handoff recorded this as a known
   trap; it is still a dead end for a wrong cancel.
6. **The facts cursor is one number but the server filters by course.** [seen]
   `backend/supabase/functions/_shared/db.ts:1436` sends `seq > since` for
   the current course list; the phone keeps a single `factsCursorV1`
   (`AppState+AppliedFacts.swift:198-201`). A class added mid-term whose
   facts were extracted at lower seqs never receives them; only a Canvas
   disconnect resets the cursor.
7. **A withdrawn fact is never removed from the phone.** [seen]
   `pruneStaleFacts` (`AppState+AppliedFacts.swift:234`) requires the local
   document to exist with a different hash. A deleted post (`gone_at`) or a
   document missing locally keeps its cancel applied forever. The server
   side only withholds (`manifest.ts:793`) and still advances the cursor, so
   a revived document's facts are never re-served either.
8. **Planner ticks and dismissals on quizzes do nothing.** [seen]
   `Reconciler.swift:185` builds `.source("quiz_<id>")` and no row anywhere
   carries that sourceID (grep finds none), so `ids()` is empty.
9. **Page rows collide across courses.** [seen]
   `Reconciler.swift:169,187` key pages by slug only (`page_<url>`); two
   courses with a `week-1` page dedupe to one row, and a tick on one
   completes the other.
10. **The on-device answerer ignores cancels.** [seen]
    `AppState+CourseKnowledge.swift:178-195` applies fact dates but `WorkItem`
    has no cancelled field; `isCancelled` is only set in
    `AssistantContextAssembly.swift:140`. Offline or over quota, "what's
    due" lists the cancelled quiz.

## Sign-in (the v9 rewrite)

11. **No "attempt still live" check after the form-detect await.** [seen]
    `LowHangingFruitUI/CanvasSessionRenewer.swift:1036-1066`: after
    `evaluateJavaScript` returns, the code goes straight to fill-and-submit.
    An attempt aborted or timed out meanwhile can submit the password into an
    untracked WebView, and a new attempt (flag reset at ~768) can submit
    again: two submissions, the one thing the rules forbid.
12. **`lastFailedCredentialSubmissionAtV1` is written and never cleared.** [seen]
    Only `AppState.swift:3987` writes it; no remove on password update,
    disconnect, or `.renewed`. A Duo timeout then blocks the corrected
    password for up to 60 minutes ("within credential spacing").
13. **The probe's `.dead` verdict is overwritten by the clock.** [seen]
    `AppState.swift:3671` sets `canvasSessionExpired = true`; the recompute
    at `:3380` (`cookieSessionExpired || loginMissing || confirmedDead`)
    runs from about a dozen sites and sets it back to false while cookies are
    under 24 h. The flag flaps per probe and `shouldRetrySilentRenewal`
    (`:2968`) sees "not expired". `sessionProbeSaidDead` is set and read by
    nothing.
14. **Disconnect / switch school do not abort a running renewal.** [reviewer]
    `AppState.swift:4796, 4732, 2508` nil the renewer without aborting; the
    old attempt lands, merges cookies (`CanvasSessionRenewer.swift:949`) and
    sets `canvasLoginEverCaptured` (`:4087`), resurrecting the account.
15. **Non-Penn or no-password dead session is a silent loop.** [reviewer]
    With stale cookies stored, `loginMissing` is false so no status line
    appears (`AppState.swift:3740`), and a hidden WebView attempt runs every
    refresh (90 s spacing) landing on the login page, indefinitely.
16. **A Duo denial or Duo failure reads as "password rejected".** [reviewer]
    `CanvasSessionRenewer.swift:1057-1066`: any later `.form`/`.formError`
    after submission settles `.passwordRejected`, which disables auto-login
    permanently and shows "pennkey password changed". Plausible, depends on
    how Penn's IdP renders after a Duo failure.
17. **Keychain save failure shows "password changed" and disables renewal.** [reviewer]
    `AppState.swift:2493` with `:3736`.

## Backend facts pipeline

18. **Retry of a finished extraction re-issues facts under new seqs.** [reviewer]
    `backend/supabase/functions/_shared/factsExtraction.ts:621-660`: delete,
    insert, update are three statements with no transaction; a run that
    dies after the insert is retried after 5 min and phones get the same
    facts twice (fact id is documentID+seq). `FactApplication.swift:336-346`
    can then mark both the old and new `new_task` redundant and hide the row.
19. **The item index is cut to the 200 oldest-due items.** [seen]
    `factsExtraction.ts:157-163` sorts oldest first then slices; a large or
    recycled course (2025 dates, CLAUDE.md trap) shows the model only past
    work, so moves of current items become `unknown_target` or duplicate
    tasks.
20. **`due_at` without an offset is accepted and read as UTC.** [seen]
    `facts.ts:421` only checks parseability; `"2026-11-10"` becomes 7 pm ET
    the day before on the card.
21. **A `reschedule` with `due_at: null` is stored; `title` is unchecked for
    length and nullable on notes.** [reviewer] `facts.ts:410-430`.
22. **One account can spend the global monthly cap.** [reviewer]
    Enrollment is only asserted (`extract-facts/index.ts:47-63`); the
    per-course cap exists, no per-user cap across courses.
23. **Last-document timeout can be 1 s with budget already charged.** [reviewer]
    `factsExtraction.ts:440-457`; three such runs give the document up for good.

## Tree (ask)

24. **Policy classification is substring matching.** [seen]
    `LowHangingFruitKit/Assistant/AskTimeFrame.swift:116` uses
    `q.contains` over `policyWords`: "example" → exam, "later" → late,
    "upgrade" → grade. Any exam word without a class or due word becomes
    `.policy`, which raises the syllabus boost to 1.5 and turns freshness
    off, so "was the midterm moved?" favours the stale syllabus more than v8
    did (`CourseSearch.swift:296-303`).
25. **Undated posts score as brand new under freshness.** [reviewer]
    `CourseSearch.swift:288-293` returns 1.0 for nil `postedAt`; a 10-day-old
    dated post scores ~0.59 against it. Related: `FactApplication.swift:393`
    sorts undated facts as the oldest, the opposite assumption.
26. **Weekday names always resolve forward; the resolved range has no
    consumer yet.** [reviewer] `AskTimeFrame.swift:217-221`, `:70-79`; latent
    until steps 3 to 6. Not a bug today, but the resolver's "Thursday" on a
    Friday means next week.
27. **`docs/PRIVACY.md` not updated with the server summary change.** [reviewer]
    `AssistantContextAssembly.swift:118,140` now sends a fact-derived moved
    date and a fourth status word `cancelled`; PRIVACY.md 208-216 still lists
    three. Commit `28e8803` broke the same-commit rule.

## Extension, scripts, workflows

28. **Shell injection with the probe secret in scope.** [seen]
    `.github/workflows/ask-probe.yml:76` runs `eval "args+=($EXTRA_ARGS)"`
    on a free-text `workflow_dispatch` input while `LHF_PROBE_SECRET` is in
    the step env; `:88` interpolates `inputs.tag`/`runs` into a `run:` script.
    Anyone with write access can exfiltrate the secret into a run log.
29. **A skipped course drops its prior submission entries while status is "in".** [seen]
    `chrome-extension/src/adapters/canvasSubmissions.js:40-48`: 403,
    truncation, or being past `MAX_COURSES` (20) rebuilds `submitted`
    without that course, so the laptop lists handed-in work again.
30. **A throw in `feedPhone` skips the whole save and is swallowed.** [seen]
    `chrome-extension/src/run.js:62` has no try/catch; `run.js:15` catches
    everything. A broken sync looks healthy.
31. **The alarm refreshes every 5 minutes unconditionally.** [seen]
    `background.js:47`; no paired, signed-out, or failure backoff (was 60
    min before `3956a8f`). Plus `THROTTLE_MS` equals the period, so about
    half the submission reads come back `throttled`.
32. **`deploy-function.mjs ask` deploys production with no gate.** [reviewer]
    CLAUDE.md says deploying `ask` needs a person's go; `--also ask` or a
    mistyped slug ships it.
33. **`feedPhone` and `deviceSyncPass` race on `snapshotV1`.** [reviewer]
    Unlocked load-mutate-save from two paths; a laptop tick can be lost.

## Design questions, not bugs (for the owners)

- Section due dates take the **earliest** override (`Reconciler.swift:234`,
  documented as deliberate). Canvas gives a student in several sections the
  latest; a student with an extension sees the early date.
- Planner `dismissed` (clearing an item from Canvas's Opportunities list)
  hides the card from todo and all (`AppState.swift:8549`). Canvas means
  "stop nagging me there", not "not work".
- `.confirmed` is never written anywhere, so "needs a look" facts can never
  be applied. Fine if Phase 5 owns it; dead code until then.
- Switching `LHF_MODEL` to Anthropic also switches `extract-announcement`,
  `extract-profile`, `map-categories` (recorded in PROTOCOL.md ~1283).
